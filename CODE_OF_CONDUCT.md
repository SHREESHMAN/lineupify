# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and accept that maintainers may close, edit or moderate contributions that do not meet that bar.

Report unacceptable behaviour privately to the maintainer listed in the package's `author` field. Reports are handled confidentially.
